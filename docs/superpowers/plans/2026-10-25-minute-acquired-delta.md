# 新采集分钟增量认证计划

目标：在不追认历史来源、不丢弃候选、不放宽独立参考门槛的前提下，用新取得的逐响应证据认证完整历史增量。

采用独立认证模块和配额绑定模块，由原候选裁决器调用。保留原单响应裁决不变，避免将多响应伪装成旧格式。
预期 consumer 由 manifest 显式声明；回溯关联独立保存，绑定未改写的原采集归档，唯一时间窗以外一律拒绝。

1. 先用合成两 symbol 增量建立失败测试，覆盖缺项、篡改、重复、错误参数、错误 consumer、配额漏项和时间窗歧义。
2. 实现逐响应原生语义认证、完整配额对账、真实回溯关联及已有精确类型和值 union 检查。
3. 在正式 evaluate 中验证原参考与隔离门槛仍生效；增加 prospective 和 uncertain 保留用例。
4. 跑分钟定点及仓库全套门禁，更新准确新增文件/行预算和退出条件，独立审查后提交 PR，暂不合并。
5. 真实采集全部完成、任务 hold 释放、原候选不变且最终证据哈希固定后，才签发新回执并完整消费重放。
