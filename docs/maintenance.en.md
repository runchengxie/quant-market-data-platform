This page summarizes repository responsibilities, accepted maintenance debt, and refactoring priorities based on governance scripts and repository-local inspection. Detailed current inventories are generated by the scripts referenced below; do not treat dated snapshots in this page as live metrics.

## Responsibilities

The repository maintains the mainland-China market-data control plane:

- Data contracts, path conventions, asset keys, manifests, dataset registry, and current contracts.
- TuShare source access for the mainland-China market.
- Guan and TuShare A-share minute construction, coverage audits, and atomic alias promotion.
- Standardized catalogs, materialization, DuckDB queries, and local snapshot backups.
- The unified `marketdata` CLI and retained archive/migration interfaces.

Hong Kong provider production modules, tick/depth modules, publication presets, transitional schedulers, and historical import wrappers were removed with RQData on 2026-07-26. Historical reproduction uses tag `hk-freeze-20260613` or the private archive repository; the recovery page is retired guidance only.

## Quality coverage and debt

After Hong Kong production directories were removed, Ruff and `ty` directory excludes were narrowed to non-source paths. Large-file excludes were removed from the core refactoring area; `data_providers.py` and `data_warehouse.py` now act as thin aggregation entry points over smaller implementations. `artifacts.py` is authoritative for artifacts-root resolution; `paths.py` retains path contracts and compatibility entry points. The default root order is explicit argument, `DATA_PLATFORM_ROOT`, then `artifacts/`. `DATA_PLATFORM_METADATA_DB_PATH` and `DATA_PLATFORM_WAREHOUSE_DB_PATH` independently override the catalog and warehouse databases.

It also records the complexity ratchet. This is a governance baseline, not a live size report. Run `scripts/dev/quality_debt.py` for current coverage and `scripts/dev/maintainability_metrics.py` for current code-shape metrics.

## Compatibility decisions

The `hkdata` console script, `hk_data_platform.*` import aliases, `rqdata-hk-depth`, `rqdata-tick`, `rqdata-hk-assets`, and retired `marketdata migration` commands were removed from the active package. The former `freeze-hk`/`hydrate-hk` interfaces were removed with RQData; the linked recovery note is retained as historical guidance.

Downstream research-repository data-directory and snapshot wrappers have been removed. Use `marketdata data ...` and `marketdata backup-data` for data operations, and `strategy ...` for strategy operations.

## Documentation and CI

The root README, `AGENTS.md`, and user-facing `docs/` are expected to reflect current behavior. Active entry points are `marketdata` and `market_data_platform`; compatibility and retirement notes live in `docs/compatibility.md`. Local gates and GitHub Actions jointly form the quality boundary: `quality.yml` checks architecture/boundaries, maintainability ratchets, Ruff, pytest, and dependency auditing; `docs.yml` runs strict documentation builds. The sdist includes `docs/` and `tests/`; the wheel contains the runtime package only. The package does not currently publish `py.typed`.

## Refactoring priorities

The recorded next steps are to split the daily executor and checkpoint/receipt finalizer in `tushare_a_share_mins.py::mirror_minute_bars`; break the monolithic minute-cutover test fixture into raw/full-day/Beijing receipt builders; continue reducing long minute-materialization and provider functions; further separate provider SDK adapters from frame-processing pipelines; and continue breaking down pandas-heavy `data_warehouse_*` modules while evaluating stricter per-module typing. RQData and the Hong Kong recovery control plane were retired on 2026-07-26 and do not need restoration drills.
